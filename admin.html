✓ Đã copy UID!
Cách cấp quyền Admin:
1Vào Firebase Console → Firestore
2Tìm collection users → document có UID ở trên
3Thêm field: role = "admin" (hoặc "super_admin")
4Nhấn Đăng xuất rồi đăng nhập lại
⚠️ Lỗi đọc Firestore — Có thể Security Rules đang chặn. Thêm rule cho phép user đọc document của chính mình:
allow read: if request.auth.uid == resource.id;
